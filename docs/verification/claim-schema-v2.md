# 主张分类与科学内容 v2 核验

日期：2026-10-17（America/Los_Angeles）。这是本地规则与工程实现记录，不是科学结果审查或宿主模型效果评价。

历史阶段记录：下述测试对应反空转门控加入前的 v2。后续 `gate_version=1` 已收紧仅观察性证据的因果正判定，并增加合成隔离、检查上限等规则；当前行为以 [反空转门控核验](anti-stall-gates.md) 为准。本页保留原始验证边界，不作为当前版本的接受证据。

## 已实现

- 规则源改为主张类型 × 类型内证据等级 + 范围，定义 12 个主张类型；类型之间没有排名。必要性、充分性分别记录。
- 因果授权记录设计族、estimand、识别假设、证伪/敏感度；不把干预存在与否作为单独门槛。
- 九个设计包、八项最低统计报告、引文/数字/执行/检索四类卡同步到规则、生成的主入口与冻结模板。
- 新案例默认 schema_version=2；台账、审查意见、裁决均校验类型与类型内等级。v2 禁止混用旧 level 字段，显式保留 UNKNOWN、NA、0 和未运行状态。
- 新字段随证据和台账冻结、进入两侧审查包并持久恢复；Markdown 与 HTML 显示原/新分类及可读的结构化记录。
- 当时的兼容实现允许显式 schema_version=1 新建案例，旧案例不迁移、不重写冻结输入。**后续 0.2.0 已关闭新建 v1 入口**，仅恢复已有历史案例并标 LEGACY_UNGATED；当前行为见 [绕过修复核验](gate-bypass-hardening-20261019.md)，此处保留阶段历史，不作为新请求指南。

## 实际验证

完整测试命令 `python -m unittest discover -s tests -v` 执行 78 项，77 通过、1 跳过（Windows 账户不能创建符号链接），无失败。完整测试包含 v1 生命周期与摘要兼容、v2 字段、因果门槛、报告转义、MCP 子进程握手、分发解压与合成演示。

随后修正通用报告被固定标为合成演示的显示问题，v2 专项 12 项、演示与分发 4 项再次全部通过。生成一致性检查通过。首次 v2 测试曾遇到沙箱硬链接权限和测试连接未关闭的问题；测试连接已修复，导出测试在获准的沙箱外本地执行后通过，未绕过原子导出保护。

关键边界案例：

- 类型与等级错配、v2 混入旧字段、卡片引用不存在证据、缺少设计检查/统计字段会被拒绝。
- 未评估或未识别的主张不能用支持/条件性支持包装。
- 观察性因果记录可以通过结构门槛；随机实验若识别假设未知仍拒绝正向因果裁决。
- estimand 未指定、敏感度失败、识别依据未被裁决引用均拒绝正向因果裁决。
- 必要性记录通过不能授权充分性；冻结后的新字段篡改会触发完整性错误。

`pass`、`checked` 仍是提交者记录。引擎不判断引用是否真正支持结论、不验证识别假设的科学真实性、不执行卡内命令，也不自动联网检索。未进行真实宿主模型使用验收、独立科研评价或用户收益测量。
