## 预填与契约读取

`scaffold_claim.prefill` 和 `draft_manuscript.claim_bindings` 读取已登记且哈希正确的快照，按显式记录选择生成完整 `ledger_payload`。支持设计包未知草稿、证据及假说 ID 绑定；保留未选记录、解析失败行和执行绑定状态。假说 origin 不自动升级，终点角色/方向不自动改成 primary/benefit，设计检查不自动通过。批量预填同时校验稿件哈希、原文和位置，防止编号未变但选句已变的错配。

这两个入口不写台账。输出提醒 `set_ledger` 会替换整份台账，并列出已有主张 ID；提交前须核对并显式合并需要保留的主张。用法见 [产物与预填指南](../artifact-ingestion.md)。

`parrhesia_contract.sections` 可一次读至多八个明确章节，父子重叠行只返回一次，并保持源哈希和原文行范围。本轮完整契约 80,283 B，目录 3,500 B；lifecycle + scaffold_claim + claim-prefill 批量正文 5,618 B。未把选择性阅读冒充全文阅读。
